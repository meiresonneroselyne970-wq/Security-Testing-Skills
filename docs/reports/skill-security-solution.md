# Skill 安全扫描解决方案

## 概述

本解决方案提供企业级的 Skill 安全扫描能力，自动检测 skill 文件中的恶意代码、隐藏危险指令和安全违规，确保 skill 上架前通过安全审核。

## 快速开始

### 1. 本地扫描

```powershell
# 扫描 skills 目录
.\scripts\skill-security-scan.ps1 -Scope skills/

# 扫描 .claude/skills 目录
.\scripts\skill-security-scan.ps1 -Scope .claude/skills/

# 扫描单个文件
.\scripts\skill-security-scan.ps1 -Scope skills/card.md
```

### 2. CI/CD 集成

项目已配置 GitHub Actions，会在以下情况自动扫描：

- **Push**: 推送代码到 `skills/` 或 `.claude/skills/` 目录
- **Pull Request**: 创建或更新 PR 涉及 skill 文件
- **手动触发**: 在 GitHub Actions 页面手动运行

### 3. Git Pre-commit Hook

创建 `.git/hooks/pre-commit` 文件：

```bash
#!/bin/bash
echo "Running skill security scan..."
powershell -ExecutionPolicy Bypass -File scripts/skill-security-scan.ps1 -Scope staged -FailOnHigh

if [ $? -ne 0 ]; then
    echo "❌ Skill security scan failed"
    exit 1
fi

echo "✅ Skill security scan passed"
```

## 安全规则

### T1 — 恶意指令注入（严重）

| 规则 | 检测项 | 威胁等级 |
|------|--------|----------|
| T1.1 | 系统命令执行 | 🔴 严重 |
| T1.2 | 文件系统破坏 | 🔴 严重 |
| T1.3 | 网络外传数据 | 🔴 严重 |
| T1.4 | 反向 Shell | 🔴 严重 |
| T1.5 | 权限提升 | 🔴 严重 |

### T2 — 隐藏危险指令（严重）

| 规则 | 检测项 | 威胁等级 |
|------|--------|----------|
| T2.1 | 零宽字符 | 🔴 严重 |
| T2.2 | 隐藏 Unicode | 🔴 严重 |
| T2.3 | 注释中的指令 | 🔴 严重 |

### T3 — 敏感信息泄露（高危）

| 规则 | 检测项 | 威胁等级 |
|------|--------|----------|
| T3.1 | API Key 硬编码 | 🟠 高危 |
| T3.2 | Token 硬编码 | 🟠 高危 |
| T3.3 | 密码硬编码 | 🟠 高危 |

### T4 — 权限越界（高危）

| 规则 | 检测项 | 威胁等级 |
|------|--------|----------|
| T4.1 | 文件系统写入 | 🟠 高危 |
| T4.2 | 文件系统删除 | 🟠 高危 |
| T4.3 | 网络请求 | 🟡 中危 |

### T5 — 社会工程攻击（严重）

| 规则 | 检测项 | 威胁等级 |
|------|--------|----------|
| T5.1 | 凭据诱导 | 🔴 严重 |
| T5.2 | 紧急诱导 | 🟡 中危 |
| T5.3 | 权限诱导 | 🟠 高危 |
| T5.4 | 绕过安全提示 | 🔴 严重 |

### T6 — 依赖与供应链（中危）

| 规则 | 检测项 | 威胁等级 |

### T7 — 合规性违规（中危）

| 规则 | 检测项 | 威胁等级 |
|------|--------|----------|
| T7.1 | 数据收集声明缺失 | 🟡 中危 |
| T7.2 | 用户同意缺失 | 🟡 中危 |
